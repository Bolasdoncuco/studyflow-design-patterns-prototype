# Design Patterns Web Practice Submission

English submission for the Design Patterns Web Practice lab.

## Main prototype

The working prototype is [StudyFlow](./04-studyflow), a local-first academic planner built with Next.js, React, TypeScript, and pnpm. It demonstrates Factory, Strategy, Repository, and MVC-style separation.

```bash
cd 04-studyflow
pnpm install
pnpm dev
```
